# Project Documentation

This directory contains supporting technical documentation for the NetSuite financial reporting integration.

- `data_model.md` describes the core data model and relationships.
- `rca_playbook.md` documents root-cause analysis guidance for reconciliation and pipeline issues.
- `interview_guide.md` provides a project walkthrough, technical interview questions and answers, reconciliation/RCA scenarios, ownership answers, and interviewer questions.

These documents support implementation, troubleshooting, and interview/demo walkthroughs of the project.
